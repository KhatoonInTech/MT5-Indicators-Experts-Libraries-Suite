CONFIRMED CODE DEFECTS AND CHANGES
1. Opposing-sequence Source previously tested only the current event's own pivot/causal CHoCH. It did not inherit the source LB through consecutive same-direction BOS/sweep events. It now walks adjacent same-direction event versions available at the current event. Historical source geometry is used; later zone expansion cannot fabricate an earlier pivot link. An intervening reversal breaks the chain. Removed sources and mitigated inherited sources do not start a new sequence. Original direct-event source behavior is preserved.
2. The previous SL -> TP policy explicitly kept the remainder open. The user's latest instruction replaces that with closing all remaining volume. Both buy and sell use the same shared method.

First SL: close 50% of then-open volume.
TP -> TP: close 25% of remaining volume.
TP -> SL: close all remaining (earlier policy retained pending clarification).
SL -> SL or SL -> TP: close all remaining.
A reversal ends the outstanding consecutive sequence. The second event remains on the same timeframe as the first. Existing retry/persistence/lot-grid behavior is retained.
