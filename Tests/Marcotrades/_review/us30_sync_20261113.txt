   symbol, timeframe or program when its own sweep geometry is unavailable.
4. Structure exits retain eligible post-entry CHoCH events across later BOS
   events, including a source LB recognized later through an explicit causal
   link. Events/LBs unavailable at the evaluation time remain excluded.
5. Structural histories capture reclassifications of the last three events
   and freeze the source pivot of each event. A CHoCH subsequently reclassified
   as a sweep ceases to qualify when that change becomes known; reclassifying
   an old event does not make it the latest market event for entry rules.
6. Entry checks log executable price, active matching-side IND count,
   nearest zone bounds, context time and ended overlapping zones. Simulation
   configuration logs expose key inputs and resolved price distances.
7. Trade indicator version 2.09/cache version 9 invalidates old results.
   Cache identity also includes the configured setup-TF list. The current
   user-edited four-TF list and existing input defaults were preserved.
